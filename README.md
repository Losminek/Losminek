# Hi, I'm Daniel

Network engineer from Czechia. At work I deal with enterprise networks
(Cisco, Huawei, FortiGate), and I know small and mid-size MikroTik networks well
(MTCNA, MTCRE, MTCTCE, MTCUME). I mostly learn on my own and like to understand *why* things work.

**What I spend my time on**
- Networking: routing, firewalling, VLANs
- Homelab: Proxmox, NAS, backups and monitoring
- AI tooling: learning to use AI assistants and agents in practice, safely

## NetKit

[NetKit](https://github.com/Losminek/netkit) is my network toolkit for Android 10+: Wi-Fi analyzer,
LAN scanner, SSH client, Wake-on-LAN and speed tests in one app. Kotlin and Jetpack Compose, Czech and
English UI, no account, ads or analytics. Signed APKs are in
[Releases](https://github.com/Losminek/netkit/releases/latest).

## Open-source contributions

Czech is my native language, so I help the [ArtCraft](https://github.com/storytold) apps speak Czech:
PdfCraft, PhotoCraft, VectorCraft, WordCraft, DesignCraft, EffectCraft and the rest of the family.
I keep the Czech interface up to date as the apps grow, and where a catalog is not enough I work on the
code around it, for example Czech spell-checking in WordCraft. When I come across a security problem in
these apps, I report it and review the fix. Now and then I send small fixes elsewhere too, for example
to [Hermes Agent](https://github.com/NousResearch/hermes-agent).

Current work is in [my pull requests](https://github.com/search?q=author%3ALosminek+type%3Apr&type=pullrequests).
Corrections from other Czech speakers are welcome there.
