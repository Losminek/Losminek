# Hi, I'm Daniel

Network engineer from Czechia. At work I deal with enterprise networks
(Cisco, Huawei, FortiGate), and I know small and mid-size MikroTik networks well
(MTCNA, MTCRE, MTCTCE, MTCUME). I mostly learn on my own and like to understand *why* things work.

**What I spend my time on**
- Networking: routing, firewalling, VLANs
- Homelab: Proxmox, NAS, backups and monitoring
- AI tooling: learning to use AI assistants and agents in practice, safely

## Open-source contributions

Czech is my native language, so I help open-source apps speak Czech. Mostly that means user-interface
translations for the [ArtCraft](https://github.com/storytold) apps. Where an app needs more than a
catalog, it also means the code around it, for example Czech spell-checking in WordCraft.

**Merged**
- [PdfCraft](https://github.com/storytold/pdfcraft), [PhotoCraft](https://github.com/storytold/photocraft),
  [VectorCraft](https://github.com/storytold/vectorcraft), [GridCraft](https://github.com/storytold/gridcraft),
  [CADCraft](https://github.com/storytold/cadcraft), [EffectCraft](https://github.com/storytold/effectcraft),
  [DesignCraft](https://github.com/storytold/designcraft), [LightCraft](https://github.com/storytold/lightcraft),
  [FigCraft](https://github.com/storytold/figcraft), [FilmCraft](https://github.com/storytold/filmcraft) and the
  [Craft Launcher](https://github.com/storytold/craft-launcher): Czech interface, kept up to date as the apps grow
- [WordCraft](https://github.com/storytold/wordcraft): completing and fixing the Czech catalog, and Czech
  spell-checking with the system Hunspell dictionary

**In review**
- [craft-i18n](https://github.com/storytold/craft-i18n), the shared catalog the apps are moving to: the Czech
  WordCraft strings added since the move
- CADCraft and FilmCraft: the strings added since their Czech catalogs landed
- EffectCraft: the panel strings added since the Czech interface landed, and Czech effect names
- [Hermes Agent](https://github.com/NousResearch/hermes-agent) (NousResearch): the terminal UI fails closed when
  the configured toolsets cannot be loaded

When I come across a security problem in these apps, I report it in a public issue and review the fixes
that follow, for example for PdfCraft's redaction.

The current list is always in [my pull requests](https://github.com/search?q=author%3ALosminek+type%3Apr&type=pullrequests).
Corrections from other Czech speakers are welcome in the pull requests.
